1. API అంటే ఏమిటి?

API (Application Programming Interface) అనేది రెండు software systems ఒకదానితో ఒకటి communicate అవ్వడానికి ఉపయోగించే interface. ఉదాహరణకు, Mobile Banking App తన balance చూపించడానికి Bank Serverకి API Request పంపుతుంది. Server ఆ Requestని process చేసి Response పంపిస్తుంది.

Request = App అడిగే సమాచారం లేదా action. Response = Server తిరిగి ఇచ్చే ఫలితం.

2. Common HTTP Methods

GET
Data retrieve చేయడానికి. Example: account details చూడటం.
POST
కొత్త data లేదా resource create చేయడానికి. Example: payment request create చేయడం.
PUT
ఒక resourceని పూర్తిగా update చేయడానికి.
DELETE
ఒక resourceని delete చేయడానికి.

HTTP method ఒక్కటే permission ఇవ్వదు. ప్రతి requestకి server authentication మరియు authorization checks చేయాలి.

4. HTTP Status Codes

  • 200 OK: Request విజయవంతంగా పూర్తయింది.
  • 201 Created: కొత్త resource create అయింది.
  • 400 Bad Request: Requestలో తప్పు ఉంది.
  • 401 Unauthorized: Valid authentication లేదు.
  • 403 Forbidden: User గుర్తించబడ్డాడు, కానీ access permission లేదు.
  • 404 Not Found: Resource దొరకలేదు.
  • 500 Internal Server Error: Serverలో unexpected error.

401 vs 403 గుర్తుంచుకోండి: 401 = sign in/authenticate కావాలి. 403 = authenticate అయ్యారు, కానీ permission లేదు.

5. API Security Checklist

  • HTTPS ఉపయోగించాలి.
  • Tokensని URLలో కాకుండా secure Authorization headerలో పంపాలి.
  • Token expiry, rotation మరియు revocation అమలు చేయాలి.
  • ప్రతి endpointలో server-side authorization check చేయాలి.
  • Input validation, rate limiting మరియు safe error handling అమలు చేయాలి.
  • Secretsని public JavaScript లేదా GitHub repositoryలో పెట్టకూడదు.

7. Your Practice Task

1. Methodని GETగా ఉంచండి. Endpoint `/api/profile` ఎంచుకోండి. Valid demo tokenతో `Send Request` నొక్కండి.

2. Tokenని `No token`గా మార్చి మళ్లీ Request పంపండి. Status code compare చేయండి.

3. ఇప్పుడు `/api/admin` endpointని ఎంచుకుని Valid demo tokenతో request పంపండి. ఎందుకు 403 వస్తుందో వివరించండి.

గుర్తుంచుకోండి: Authentication అంటే User ఎవరో నిర్ధారించడం. Authorization అంటే ఆ User ఏ data లేదా action access చేయవచ్చో నిర్ణయించడం.
