3. Secure query pattern
SELECT id, username
FROM users
WHERE username = ?
  AND password_hash = ?;
Placeholders keep values separate from SQL instructions. Real apps must verify password hashes, not store plaintext passwords.




4. Learning check
Why are placeholders safer?
Placeholders send values separately from SQL instructions. The database treats supplied text as data rather than executable SQL syntax, so input cannot change the query structure.
